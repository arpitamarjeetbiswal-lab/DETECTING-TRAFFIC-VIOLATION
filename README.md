# Traffic Violation Detection

A React dashboard and Flask service for image-based motorcycle, helmet, and number-plate analysis. OCR output is an estimate and must be reviewed before use.

## Current capabilities

- Upload an image from the frontend and receive annotated detection results from Flask.
- Detect motorcycles, people, helmet status, and number plates.
- Estimate rider counts per motorcycle and flag possible triple riding for review.
- Associate plate detections with motorcycles when the overlap is clear.
- Save no-helmet violations and a confidently associated plate number to SQLite; otherwise save `NOT_AVAILABLE`.
- Display plate text, confidence, and review status in the upload results.

Detection quality depends on image resolution, camera angle, lighting, and model training. Small or unclear plates may be reported as unreadable or incorrect; review all results.

## Requirements

- Python 3.10 or newer
- Node.js 20.19+ or 22.12+
- Git
- PyTorch and TorchVision. Install the build suited to your machine from the [official PyTorch installer](https://pytorch.org/get-started/locally/). For an NVIDIA GPU, select the installed CUDA option; CPU builds also work but are slower.

## Setup on Windows PowerShell

Run these commands from the repository root.

### 1. Install Python dependencies

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Install PyTorch and TorchVision using the command generated by the [official PyTorch installer](https://pytorch.org/get-started/locally/). Select the matching CUDA build for NVIDIA GPU acceleration; the CPU build works too, but inference is slower. Then install the remaining Python dependencies:

```powershell
python -m pip install -r requirements.txt
```

If Python 3.12 is unavailable, use another installed Python version 3.10 or newer in the `py -3.12` command.

### 2. Start the Flask backend

Open a PowerShell window at the repository root:

```powershell
.\.venv\Scripts\Activate.ps1
python ai\scripts\flask_api.py
```

The API listens at `http://127.0.0.1:5000`. The first OCR run may download EasyOCR language data.

### 3. Start the frontend

Open a second PowerShell window at the repository root:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173`.

## Model files

- `ai/models/best.pt` is the helmet model already tracked in Git.
- `yolov8n.pt` is used for person and motorcycle detection.
- `ai/runs/plate_detection/test_training_v2/weights/best.pt` is the trained plate detector used by the OCR service.

The last two model files are binary assets. Include them in the contribution only if their source and redistribution terms permit it. Do not add datasets, uploads, generated outputs, or the local SQLite database to a code commit.

## Git contribution scope

Review and contribute the code/documentation files deliberately. Keep `.venv*`, `node_modules`, datasets, uploads, generated run outputs, and `ai/traffic_violations.db` out of commits. Model weights should be reviewed for provenance and repository hosting limits before adding.
