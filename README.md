# IoT-Based Intelligent Traffic Monitoring System

## Project Description

An IoT-enabled intelligent traffic monitoring system developed using Raspberry Pi, YOLOv8, OpenCV, and EasyOCR. The system automatically detects helmet violations, recognizes vehicle number plates, and reports traffic violations through a Node.js REST API. It also provides a web dashboard for monitoring and managing detected traffic violations.

## Technologies Used
- Raspberry Pi
- YOLOv8
- OpenCV
- EasyOCR
- Node.js
- REST API
- React.js
